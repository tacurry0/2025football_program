# 2026/27 選手分析・対戦分析の自動更新

`Update trapp player analysis` ワークフローが、日本時間の毎日21:37・翌0:37・6:37に公式サイトを確認します。GitHub Actions の混雑時は遅延することがあります。Actions画面の「Run workflow」でも実行できます。

初期データは2026-09-13まで。新潟8試合（J2 6・ルヴァン1・天皇杯1）、熊本8試合（J3 6・ルヴァン1・天皇杯1）。最新の対象日・試合数は `data/generated/update.json` を参照してください。

## 更新の流れ

1. `update_player_analysis.py` がJ1/J2/J3・ルヴァン・天皇杯のシーズン月別結果を取得。J1は対戦相手の分析専用です。順位表はJ2/J3を取得します。
2. 新潟・熊本の終了済み公式戦の先発、ベンチ、交代、得点、カードを取得。GASと同じ `gas/JLeague.gs` のパーサーをNodeで再利用します。外部ページのJavaScriptは実行しません。
3. 一時ディレクトリで集計し、結果と詳細のスコア一致・両チーム11人の先発・既知の試合の収録を確認。失敗時は前回の公開ファイルを維持します。
4. 選手別・通算データ、過去の対戦一覧、ファイルハッシュ付き更新情報を同じコミットで公開します。過去の公式訂正も次の更新で取り込みます。
5. 選手分析画面を開いたとき、または表示中5分ごとに更新を確認。完全なデータ一式のSHA-256を検証してから表示を切り替えます。検証済みデータは端末にも保存します。起動アニメーション中には取得しません。

自動更新データはGitHubの公開rawファイルから読み込みます。GitHub ActionsのコミットによるPages再ビルドの有無に依存しません。通信できないときは端末の検証済みデータ、初回は同梱ファイルを表示します。更新確認ボタンは公開済みデータの再確認で、GitHub Actionsを起動するボタンではありません。

## 手元で実行

Python 3.12、Node.js 22を使用。追加パッケージ・APIキー・GASの差し替えは不要です。

```sh
PYTHONDONTWRITEBYTECODE=1 python trapp/data/scripts/update_player_analysis.py
node --test trapp/tests/*.test.cjs
PYTHONDONTWRITEBYTECODE=1 python -m unittest discover -s trapp/tests -p 'test_*.py'
```

`GITHUB_TOKEN` の `contents: write` で更新します。リポジトリや組織のポリシーでActionsまたは書き込みが禁止されている場合は、Actionsの失敗ログを確認してください。2027年7月末以降は意図的に更新を停止するため、次シーズンの設定変更が必要です。

分析の数値年度キーは終了年 `2027`、表示は `2026/27`、ファイル名は `2026_2027`。百年構想リーグは従来の2026データに残し、日程・カレンダーは暦年の表示を維持します。練習試合・県予選は自動集計の対象外。PK戦は通常スコアと分け、勝敗集計では同点試合を引き分けとして扱います。

## スタジアム訪問

メニューの「スタジアム訪問」から日付・座席・写真・メモを記録できます。観戦予定は訪問済みとは分け、過去の予定から記録フォームへ引き継ぎます。保存先は端末の `trapp_stadium_visits_v1`。写真はJPEGに縮小し、既存のデータ管理のバックアップに含めます。

地図は画面を開いてからLeaflet 1.9.4を読み込みます。地図を取得できないときも訪問リスト・記録フォームは使えます。登録済みスタジアムの位置を利用でき、未登録の場合は地図上のタップまたは緯度・経度で指定できます。座標が不明なままでもリストに保存できます。

地図・スタジアム座標: © [OpenStreetMap contributors](https://www.openstreetmap.org/copyright) / ODbL。`data/stadiums.json` の各 `source` が座標の出典です。少量の一度きりの座標照合結果を同梱し、アプリからの自動地名検索は行いません。タイルの一括取得・先読み・オフラインダウンロードは実装していません。[タイル利用ポリシー](https://operations.osmfoundation.org/policies/tiles/)に従い、地図上の帰属表示を維持します。Leafletのライセンスは `vendor/leaflet/LICENSE`。
