# 2026/27 選手分析データ

2026-09-12時点の終了済み公式記録を収録。新潟7試合（J2 5・ルヴァン1・天皇杯1）、熊本8試合（J3 6・ルヴァン1・天皇杯1）。熊本の9月12日福島戦を含む。

先発・ベンチ・交代・得点・カードは `data/details/2026_2027/` のJリーグ公式記録から生成する。練習試合と県予選は、このデータセットの対象外。PK戦は通常の試合スコアと分けて保持し、既存集計に合わせて同点試合の勝敗集計は引き分けとする。

再生成:

```sh
PYTHONDONTWRITEBYTECODE=1 python trapp/data/scripts/build_2627_player_analysis.py --through 2026-09-12
```

更新するときは先に新しい終了済み試合のGAS詳細レスポンスを `data/details/2026_2027/{competition}/{match_id}.json` に保存し、対象日を指定する。既知の結果に対応する詳細がない場合は生成を停止する。現時点の集計は自動更新ではなく同梱スナップショット。

出力は `data/generated/{club}/2026_2027/` と `data/history/{club}/2026_2027.json`。分析画面の数値年度キーだけは終了年の `2027` とし、表示名は `2026/27`、ファイルのシーズンIDは `2026_2027`。通算ファイルへの再追加は重複しない。2026年の百年構想リーグは従来ファイルを維持し、日程・カレンダーは引き続き暦年で表示する。

各クラブの `metadata.json` に対象日・最終試合日・試合数・公式URLを記録。
